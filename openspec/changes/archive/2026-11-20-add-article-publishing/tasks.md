## 2. 发布与阅读 API

- [x] 2.1 实现发布接口及事务，验证登录、CSRF、作者隔离、请求版本和已保存标题正文的校验。验证成功后原 ID、正文与首次发布时间可读取，版本只增加一次。

- [x] 2.3 实现已发布文章的按 ID 阅读，验证未登录返回 `401`，草稿与不存在的内容返回 `404`，发布提交后已关注和未关注的登录用户都能读取原 ID。
